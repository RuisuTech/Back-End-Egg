# Back-End Egg

Repositorio de práctica de programación en Java, enfocado en desarrollo backend. Contiene ejercicios y actividades organizadas por temáticas de programación orientada a objetos y fundamentos de Java.

## Estructura del Proyecto

### Fundamentos de Java
- **HolaMundo/** - Primeros pasos en Java
- **TiposDeDatos/** - Variables y tipos de datos primitivos
- **ClaseScanner/** - Entrada de datos por consola
- **Clase-Math/** - Métodos matemáticos de la clase Math

### Operadores y Control de Flujo
- **Control-If/** - Sentencias condicionales if-else
- **Control-Switch/** - Sentencias switch
- **Control-TryCatch/** - Manejo de excepciones con try-catch

### Estructuras de Repetición
- **Bucles/** - Ciclos for y while (nivel básico)
- **Bucles-2/** - Ejercicios avanzados de bucles

### Métodos
- **Metodos/** - Definición y uso de métodos
- **Metodos-2/** - Ejercicios prácticos con métodos
- **Metodos-3/** - Algoritmos: factorial, Fibonacci, primos

### Arrays
- **Arrays/** - Operaciones con arreglos (búsqueda, ordenamiento, copia)
- **Arrays-2/** - Búsqueda binaria, comparación y manipulación de arreglos

### Strings
- **PracticandoStrings/** - Manipulación de cadenas de texto

### Programación Orientada a Objetos (POO)
- **POO/** - Clases, objetos, atributos y métodos
- **Encapsulamiento/** - Principio de encapsulamiento (getters/setters)
- **Herencia/** - Relaciones de herencia entre clases
- **POO-Avanzado/** - Composición y relaciones entre objetos
- **POO-AVANZADO-2/** - Ejercicios avanzados de POO
- **POO-AVANZADO-3/** - Biblioteca y gestión de objetos
- **POO-AVANZADO-4/** - Excepciones personalizadas
- **POO-ACTIVIDAD/** - Interfaces y polimorfismo

### Temas Avanzados
- **Enums/** - Enumeraciones en Java
- **Wrappers/** - Clases wrapper (Integer, Double, etc.)
- **Debugger/** - Técnicas de depuración
- **COLLECTION/** - Colecciones (ArrayList, LinkedList)
- **HASHSET/** - Conjuntos HashSet

### Actividades
- **Actividad-2/** - Contraseña y conversión de temperatura
- **Actividad-3/** - Estadísticas, Fibonacci, primos y contraseñas
- **Actividad-4/** - Factorial, gráficos de barras y números primos
- **Actividad-5/** - Manipulación de oraciones
- **Actividad-6/** - Registro de alumnos
- **Actividad-7/** - Modelos de datos
- **ActividadIntegradora-1/** - Calculadora básica e identificador par/impar

## Tecnologías

- **Lenguaje:** Java
- **IDE:** Compatible con cualquier IDE Java (IntelliJ, Eclipse, VS Code)
- **JDK:** Versión 8 o superior

## Cómo Ejecutar

1. Compilar el archivo Java:
   ```bash
   javac NombreArchivo.java
   ```

2. Ejecutar la clase principal:
   ```bash
   java NombreArchivo
   ```
